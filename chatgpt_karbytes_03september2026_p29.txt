### The naming change

The first cyan-highlighted proposition announces that KARBYTES will stop using solitary English letters to distinguish multiple same-day `journal_karbytes` or `chatgpt_karbytes` pages.

* `a` plus a nonnegative decimal integer for a WordPress page

* `p` plus a nonnegative decimal integer for a plain-text source file

* `pN` = plain-text/source index
