To Whom It May Concern:

Rather than append single letters of the English alphabet to the end of the names of WordPress dot Com web pages of KARBYTES (which have either the prefix journal_karbytes or else the prefix chatgpt_karbytes), I decided that I will use a different method of indexing "same-day" web pages (of the specified web page types).

There are two reasons for that change:

1. Some letters of the English alphabet (especially lower-case versions of those letters) such as I, L, and O are visibly difficult to distinguish from some numberic digits sich as 1 (i.e. one) and zero (i.e. 0) and/or from some other English alphabet characters (particularly lowercase I and lowecase L).

2. There are only 26 letters of the English alphabet (which means that "same-day" pages of the same KARBYTES blog post type (i.e. chatgpt_karbytes or journal_karbytes) are limited to no more than 26 (which means that additional pages of such a set would carry over into the next calendar day in terms of web page naming)).

The new KARBYTES web page naming convention (for chatgpt_karbytes or journal_karbytes type (WordPress dot Com (within the website named Karbytes For Life Blog dot WordPress dot Com)) web pages) entails appending the web page names with the (lowercase) letter A followed by a nonnegative (decimal) integer which corresponds with the respective web page's "source plain-text" file (and the corresponding plain-text file name entails appending the (lowercase) letter P followed by a nonnegative (decimal) integer).

An example of this new KARBYTES file naming convention being implemented is the following plain-text file and WordPress dot Com web page pairing:

  { 

    plain-text_file_url: 

    https://raw.githubusercontent.com/karlinarayberinger/KARLINA_OBJECT_extension_pack_76/main/journal_karbytes_03september2026_p1.txt
